## 🌌 Overview

Meridian Career OS is a meticulously engineered MERN-stack platform built for the modern node. It features a hyper-optimized **Obsidian Architect** frontend design language featuring pure black backgrounds, fluid canvas animations, and striking `#d856b8` (magenta) glassmorphic interactive elements.

Designed entirely as a responsive Single Page Application (SPA), it eliminates navigational friction and embraces a dark, immersive workspace for developers.

### ✨ Key Visual Features
* **Interactive Starfield & Pixel Voyager**: The landing page implements a lightweight 2D canvas 550-star ecosystem, accompanied by a cursor-tracking pixel art rocket and a vivid magenta fading particle trail. 
* **Floating Glassmorphic Navigation**: A transcendent top bar with dynamic backdrop blur that responds to scroll physics.
* **Unified Application Layout**: Inside the authenticated console, a custom draggable Sidebar dynamically resizes between 220px and 500px, persisting alongside an automated animated Dotted Surface background (`three.js`).
* **Hyperspeed Tunnel Authorization**: The Auth portal surrounds the user in a breathtaking three.js Post-Processing light-speed tunnel.

## 🛠️ Tech Stack & Architecture

### Frontend (Client)
* **Vite + React (JSX)**
* **Tailwind CSS** (Custom extending with `#d856b8` glow layers and `surface-container` hierarchy)
* **Framer Motion** (Spring-physics UI mounting and layout orchestrations)
* **Three.js & React-Three-Fiber** (Immersive WebGL data visualization backgrounds)
* **Zustand** (Global state management)

### Backend (Server)
* **Node.js runtime**
* **Express.js API Layer**
* **MongoDB + Mongoose** schemas directly aligned with OS Architect definitions
* **JWT Authorization** + Secure Cookie sessions

## 🚀 Initialization Sequence

### 1. Requirements
* Node.js v18+
* MongoDB running instance

### 2. Edge Node Deployment
Clone the repository:
```bash
git clone https://github.com/TejasSharma356/Meridian.git
cd Meridian
```

### 3. Uplink Server
```bash
cd server
npm install
npm run dev
```

### 4. Ignite Client
Open a second terminal:
```bash
cd client
npm install
npm run dev
```
